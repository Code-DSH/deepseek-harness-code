# DeepSeek Harness Code 0.1.0-BETA2-1

This release is a community wrapper and is not an official DeepSeek release.

## Fixes

- Fixes the persistent Bash PTY readiness hang by using the unique
  `__DSH_PERSISTENT_BASH_PROMPT__` prompt and deriving the prompt-tail bound
  from its actual length.
- Carries the fix through the reproducible `config/node-runtime` pnpm patch
  and packaged runtime lockfile.
- Enables user-confirmed update download, SHA-256 verification, platform
  replacement, and restart. There is no silent background replacement.
- Publishes an architecture-aware `update-manifest.json` alongside the
  Universal macOS, Windows x64/arm64, and Linux x64/arm64 artifacts.
- Allows GitHub’s signed `release-assets.githubusercontent.com` redirect host
  during update download while retaining HTTPS, redirect re-validation, and
  private/loopback rejection.

## Update behavior

Use 设置 → 通用 → 检查更新. When a newer release is found, choose “Update and
restart” to download and verify the platform package before the app exits for
the replacement helper. The app must be installed from a persistent location;
DMG-mounted and Gatekeeper-translocated paths are refused.

The macOS package remains ad-hoc signed and not Apple-notarized. See
[install-unsigned.md](../operations/install-unsigned.md) for targeted
quarantine guidance.
