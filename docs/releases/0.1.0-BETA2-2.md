# DeepSeek Harness Code 0.1.0-BETA2-2

> **状态：pending cloud release gate。** DeepSeek Harness Code 是社区发行版，不是 DeepSeek 官方产品。首个 `v0.1.0-BETA2-2` 标记指向 `012527f059c5888c64830c68a7182104f36998c4`，但未产生 GitHub Release；当前文档不得写“已全绿”“已发布”或资产 hash。

## Highlights

- Adds the official-format `dsh-lan-access` plugin. LAN access is disabled by default. When a user explicitly enables it, Electron starts a separate authenticated, token-gated reverse proxy on `0.0.0.0`; the Harness server and the desktop renderer continue to use loopback.
- Keeps the token-bearing LAN URL in Electron main. Every native Copy action issues a fresh one-time link and invalidates any prior unredeemed link; the renderer receives only redacted state.
- Labels LAN access as trusted-LAN HTTP only. It makes no Internet-exposure, NAT-traversal, or TLS claim. Disabling the setting closes the listener and invalidates its token.
- Adds a validated app-owned plugin-reconciliation marker. An unchanged managed roster skips repeated official CLI additions; a missing marker, changed package root or identity, missing profile dependency, or foreign store repeats official reconciliation.
- Updates Windows custom Bash to join the DSH session policy and canonical workdir boundary. `str_replace_editor` uses the host sandboxed filesystem. DSH rc.8 does not promise universal read isolation, and canonical preflight retains a filesystem TOCTOU residual risk.
