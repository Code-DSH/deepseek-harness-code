# DeepSeek Harness Code 0.1.0-BETA2-2

> **状态：已发布 / GitHub Latest。** DeepSeek Harness Code 是社区发行版，不是 DeepSeek 官方产品。`v0.1.0-BETA2-2` 指向 `6a08c985cf0090bfdc20e1d0d07f916393668501`；正式 package/publish Run [32502448560](https://github.com/Code-DSH/deepseek-harness-code/actions/runs/32502448560) 全绿，Release 位于 [v0.1.0-BETA2-2](https://github.com/Code-DSH/deepseek-harness-code/releases/tag/v0.1.0-BETA2-2)。

## 主要修复

- 将首次启动的完整托管插件 roster 合并为每次尝试一次无 shell 的官方 `dsh plugin --profile web add` 调用，修复 BETA2-1 首次安装时逐插件同步过慢、并发包操作不稳定的问题。
- 统一使用系统安装的官方 Node.js `>=22.13`。缺少 Node 时只显示官方、按平台架构匹配的安装链接，不会静默下载或伪称已经自动安装。
- Windows NSIS 改用 ZIP payload，绕过 Windows arm64 上会静默留下不完整安装目录的原生 7z 解包链；x64/arm64 均完成真实安装、首次启动、无 Node 指引和卸载验证。
- 新增原生架构绑定、精确 Harness listener PID、`127.0.0.1` HTTP 探测、ready duration、干净退出及端口关闭证据。
- 新增默认关闭的官方格式 `dsh-lan-access` 插件。只有用户显式启用时才启动 Electron 持有的一次性 token 代理；Harness 和桌面 renderer 继续仅绑定 loopback。该功能只面向可信局域网 HTTP，不承诺公网暴露、NAT 穿透或 TLS。
- 保留 Windows custom Bash 的 DSH 会话策略与规范工作目录边界；`str_replace_editor` 继续使用宿主沙箱文件系统。

## 下载与更新

Release 包含 Universal macOS DMG/ZIP、Windows x64/arm64 NSIS、Linux x64/arm64 AppImage/deb，以及 `update-manifest.json`。Manifest 中 5 个应用内更新目标的文件名、字节数和 SHA-256 已与 GitHub Release 资产记录逐项匹配。

旧版本可在应用内使用 **Check for updates** 获取 BETA2-2；更新仍需用户确认，并在替换前验证整包 SHA-256。macOS 包为 ad-hoc 签名、未经过 Apple notarization，安装时请使用[限定范围的说明](https://github.com/Code-DSH/deepseek-harness-code/blob/main/docs/operations/install-unsigned.md)，不要全局关闭 Gatekeeper。

BETA2-1 因严重首次安装问题已于 2026-08-21 紧急下架 GitHub Release/资产；其源码 tag 与归档文档保留用于审计。
