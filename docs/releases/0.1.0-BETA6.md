# DeepSeek Harness Code 0.1.0-BETA6

> **测试版本。** 本版本用于验证从 BETA5 到新版本的应用内更新流程，不代表新增 Harness 功能或稳定版承诺。

DeepSeek Harness Code is a community distribution, not an official DeepSeek product.

## Purpose of this test release

- Publishes a new version for exercising the user-confirmed update flow.
- Keeps the BETA5 bounded, scrollable update panel and fixed bottom actions unchanged.
- Uses the same SHA-256-verified, architecture-aware update manifest and native package gates.

## Update from BETA5

Open **Settings → General → Check for updates** in a BETA5 installation. The app should read the GitHub Latest `update-manifest.json`, offer `0.1.0-BETA6` when it is newer, show long notes inside the scrollable content area, keep the download action visible, and verify the selected asset's byte size and SHA-256 before restart.

The test release publishes Universal macOS DMG/ZIP, Windows x64/arm64 NSIS, Linux x64/arm64 AppImage/deb, and `update-manifest.json` after the tag workflow completes its native package and smoke gates.

## Requirements and known limit

- Node.js `^22.19.0 || >=24.0.0` is required; Node 23 is unsupported.
- macOS remains ad-hoc signed and not Apple-notarized. Use the [app-scoped unsigned installation instructions](../operations/install-unsigned.md).
